# NADAV Core vs. NADAV Food

| Tema | NADAV Core | NADAV Food |
| --- | --- | --- |
| Producto | Infraestructura reutilizable | SaaS gastronómico listo para contratar |
| Storefront | Totalmente reemplazable | Menú público del SaaS |
| Planes | Feature flags por proyecto | Basic / Pro / Premium |
| Billing NADAV | No | Sí |
| Alta autoservicio | No | Sí |
| Superadmin comercial | No | Sí |
| Demos comerciales | Demo genérica técnica | Demos de marca |
| Mercado Pago | Cuenta del restaurante para pedidos | Cuenta del restaurante + billing NADAV |
| Despliegue inicial | Dedicado por cliente | Multi-tenant |

No existe dependencia de ejecución entre ambos proyectos. NADAV Food permanece autónomo y Core no consume su base de datos.
